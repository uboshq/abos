# ব্যাকআপ — সার্ভারে কী বসাতে হবে

> ⛔ **১৫ সেপ্টেম্বর ২০২৬-এ ধরা পড়েছে: লাইভে ব্যাকআপ ছয় দিন ধরে ব্যর্থ
> হচ্ছিল, আর প্রতিদিন "DONE" লিখত।** এই ফাইলটা সেই ঘটনার ফল।

---

## কী ভেঙেছিল

দুইটা আলাদা রোগ, আর **দ্বিতীয়টা অনেক বেশি খারাপ**:

| | রোগ | ধরন |
|---|---|---|
| ১ | `abos:backup` শেয়ার্ড হোস্টিংয়ে চলত না — `proc_open` বন্ধ, আর `Symfony\Process` ওটা ছাড়া চলে না | পরিবেশের সীমা |
| ২ | ব্যর্থতাটা **কোথাও লেখা হত না** | ⛔ এটাই ছয় দিন লুকিয়ে রেখেছিল |

⚠️ প্রথমটা সারানো যায়, আর সারানো হয়েছে। কিন্তু দ্বিতীয়টা না সারালে
পরের ভাঙনটাও ঠিক একইভাবে নীরব থাকত।

---

## এখন তিনটা স্তর, আর তিনটাই আলাদা

### ১. PHP-র নিজের ডাম্প (ডিফল্ট)

`App\Core\Services\Backup\PdoDumper` — বাইরের কোনো প্রোগ্রাম ছাড়াই ডাম্প
নেয়। ⓘ `proc_open` বন্ধ থাকলে `abos:backup` নিজে থেকেই এই পথে যায়।

```bash
php artisan abos:backup
```

⚠️ এই ডাম্পার **ভিউ, রুটিন, ট্রিগার বা ইভেন্ট ধরে না**। আজকের স্কিমায়
ওগুলো নেই (গুনে দেখা), আর কেউ বসালে ডাম্পার **থেমে যায়** — নীরবে
অসম্পূর্ণ ব্যাকআপ নেওয়ার চেয়ে জোরে থামা ভালো।

### ২. শেল থেকে `mysqldump` (দ্বিতীয় পথ)

`infra/backup-abos.sh` — cron থেকে সরাসরি, PHP-র সীমার বাইরে।

```bash
cp infra/backup-abos.sh ~/backup-abos.sh
chmod +x ~/backup-abos.sh
~/backup-abos.sh                 # ⚠️ একবার হাতে চালিয়ে দেখুন
```

cPanel ▸ Cron Jobs ▸ Add New Cron Job:

```
0 2 * * *  /bin/bash $HOME/backup-abos.sh >> $HOME/backup-cron.log 2>&1
```

ⓘ স্ক্রিপ্টটা নিজেই যাচাই করে: gzip খুলে দেখে, `CREATE TABLE` গোনে, আর
শূন্য পেলে ফাইলটা **রাখে না**।

### ৩. ⭐ পাহারা — আর এটাই সবচেয়ে দরকারি

```bash
php artisan abos:backup-fresh
```

শেষ কাজের ব্যাকআপ **৪৮ ঘণ্টার** বেশি পুরনো হলে চিৎকার করে: কনসোলে,
`storage/logs/backup.log`-এ, `laravel.log`-এ, আর exit code-এ।

⚠️ **এটা কমান্ডের দাবি শোনে না, ফাইলটা দেখে।** পার্থক্যটা মূলে:

- `onFailure` কেবল তখনই চলে যখন কমান্ড **চলে এবং ব্যর্থ হয়**
- ⛔ cron বন্ধ হলে, বা শিডিউলের শর্ত কোনোদিন সত্যি না হলে, সে **কোনোদিন
  ডাকাই হয় না** — আর নীরবতা তখন সাফল্যের মতো দেখায়

ⓘ শিডিউলে দিনে দুইবার বসানো (৯টা ও ৯টা), `routes/console.php`-এ।

## ⚠️ যা মনে রাখতে হবে

**ফাইল থাকা প্রমাণ নয়।** একটা ফাইল থাকতে পারে, আকার ঘোষণা করতে পারে,
আর ভিতরে এক বাইটও না থাকতে পারে। ⓘ তাই প্রতিটা স্তরেই যাচাইটা
**ফিরিয়ে এনে গুনে দেখা** — অস্তিত্ব দেখা নয়।

**`schedule.log` সত্যিই `FAIL` লিখত — কেউ খোলেনি, এটাই আসল কথা।**

⛔ এই ফাইলে আগে লেখা ছিল "শিডিউলার exit code দেখে ঐ লাইনটা লেখে না"।
**কথাটা ভুল ছিল, আর সংশোধন করা হলো।** `ScheduleRunCommand::runEvent()`
শেষ করে `return $event->exitCode == 0;` দিয়ে, আর ঐ উত্তরটাই `DONE` না
`FAIL` ঠিক করে। `abos:backup` ব্যর্থ হলে `FAILURE` ফেরত দেয়,
`abos:backup-due` সেটা পাস করে দেয় — অর্থাৎ শৃঙ্খলটা গোড়া থেকে সৎ।

⚠️ তাহলে ছয় দিন কেউ জানল না কেন? কারণ `FAIL` লেখা হচ্ছিল এমন এক ফাইলে
**যা কেউ খোলে না**। ⭐ রোগটা যন্ত্রের সততায় ছিল না, ছিল আমাদের তাকানোয়।

ⓘ তাই `abos:backup-fresh` লগে ফিসফিস করে না — `logger()->critical()`,
`backup.log`, console আর non-zero exit, চারটা পথেই একসাথে বলে।

ⓘ কারণ খুঁজতে হলে `storage/logs/backup.log`, তারপর `laravel.log`।

## যা এখনো বাকি

⛔ **দ্বিতীয় গন্তব্য (`ABOS_BACKUP_MIRROR`) এখনো বসানো নেই।** একই ডিস্কে
রাখা ব্যাকআপ ডিস্ক ফেল করলে ব্যাকআপও নিয়ে যায় — অর্থাৎ যে একটা ক্ষেত্রে
ব্যাকআপ সবচেয়ে বেশি দরকার, ঠিক সেখানেই সেটা নেই।

⭐ **মালিক সিদ্ধান্ত দিয়েছেন, ১৫ সেপ্টেম্বর ২০২৬: অন্য ডিস্ক বা পেনড্রাইভ।**

ⓘ অর্থাৎ বাকি আছে কেবল **পথটা** — কোন ড্রাইভ, কোন ফোল্ডার। জানা হলে
`.env`-এ এক লাইন, আর কোড নতুন করে ছোঁয়ার দরকার নেই:

```
ABOS_BACKUP_MIRROR=/mnt/backup2/abos      # বা  D:\abos-backup
```

⚠️ তিনটা শর্ত, আর তিনটাই আসল:

| শর্ত | কেন |
|---|---|
| **আলাদা ভৌত ডিস্ক** | একই ডিস্কের অন্য পার্টিশন কিছুই বাঁচায় না — ডিস্ক মরলে দুইটাই মরে |
| **সবসময় লাগানো** | পেনড্রাইভ খুলে রাখলে কপিটা নীরবে বাদ পড়ে, আর কেউ জানে না |
| **PHP-র লেখার অনুমতি** | নইলে মূল ব্যাকআপ হয়, মিরর হয় না — আবার সেই নীরব অর্ধ-সফলতা |

⓵ পথটা বসানোর পর **প্রমাণ নাও, ধরে নিও না**:

```bash
php artisan abos:backup          # exit code 0 হতে হবে
ls -l /mnt/backup2/abos          # আজকের তারিখের ফাইলটা সত্যিই আছে?
php artisan abos:backup-fresh    # পাহারাটা চুপ থাকলে তবেই ঠিক আছে
```

⛔ ⓘ ততদিন পর্যন্ত মনে রাখা দরকার: আজ ব্যাকআপ **একটাই কপি**। ওটা ছয়
দিনের নীরবতার চেয়ে ভালো, কিন্তু নিরাপদ নয়।
