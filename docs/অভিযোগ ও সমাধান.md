# অভিযোগ ও সমাধান

মালিক যা যা ভুল দেখেছেন, তারিখ ধরে। **নতুনটা উপরে।**

## কেন এই কাগজটা

চ্যাটের কথা হারিয়ে যায়। পরের সেশন শুরু হয় খালি হাতে, আর তখন একই
অভিযোগ দুইবার খোঁজা হয় — বা আরও খারাপ, একবারও না।

তাই নিয়মটা: **অভিযোগ এলে আগে এখানে সারি বসে, তারপর খোঁজা শুরু হয়।**
খোঁজার পর নয় — কারণ ততক্ষণে কী বলা হয়েছিল সেটাই ঝাপসা হয়ে যায়।

প্রতিটা সারিতে থাকে: কী দেখা গেছে, কোন পর্দায়, কোন অ্যাকাউন্টে, আর
মেপে কী পাওয়া গেল। **নিজের দোষ হলে সেটাও ওই ভাষাতেই লেখা।**

### ১ · লাইভে থিম বদলায় না · **আমার ভুল ছিল**

| | |
|---|---|
| **কী বলা হয়েছে** | "abos bortoman live e theme change hoyna, module change hoyne" |
| **কোথায়** | `abos.univer.com.bd` · চেহারার পাতা · মালিকের নিজের অ্যাকাউন্ট |
| **অবস্থা** | 🔴 খোলা — একটা কারণ পাওয়া গেছে ও সারানো, কিন্তু মালিক বলছেন **"ekhono ager motoi"** |

**যা মেপে পাওয়া গেছে**

থিম লাইভে সত্যিই বদলায় — অ্যাট্রিবিউট নয়, **আসল রং** মেপে দেখা:

| রূপ | টপবারের রং | সারির উচ্চতা |
|---|---|---|
| navy | `#ffffff` | 44px |
| apps | `#714b67` (ওডুর বেগুনি) | 44px |
| dynamic | `#0b2a4a` | 44px |
| tiles | `#354a5f` | **32px** |
| suite | `#2e4b6b` | **24px** |

সিস্টেমও সুস্থ: MySQL চলছে, ১২১ টেবিল, আজ লগে **একটাও ভুল নেই**।

**প্রথম কারণ — আর সেটা আমি**

লাইভে পরীক্ষা চালাতে গিয়ে আমি **মালিকের নিজের অ্যাকাউন্টের `ui` কলাম
বারবার বদলাচ্ছিলাম**। তিনি একটা রূপ বাছছিলেন, আর আমার স্ক্রিপ্ট কয়েক
সেকেন্ড পরেই আরেকটা বসিয়ে দিচ্ছিল। শেষ রানটা `suite`-এ থামিয়ে রেখে
ফেরতও দেয়নি।

তাঁর পর্দায় সেটা দেখাত ঠিক "থিম বদলায় না" — বদলাত, তারপর নিজে থেকেই
ফিরে যেত।

`apps / light`-এ ফিরিয়ে দেওয়া হয়েছে। নিয়ম লেখা হয়েছে: **লাইভ পরীক্ষা
কখনো মালিকের অ্যাকাউন্টে নয়।**

**কিন্তু সমস্যা রয়ে গেছে**

ফেরত দেওয়ার পরও মালিক বলছেন আগের মতোই। অর্থাৎ **দ্বিতীয় একটা কারণ
আছে**, আর সেটা এখনো পাওয়া যায়নি।

যা এখনো দেখা বাকি:

- কোম্পানি ৩ (`PROV`)-এ **তিনটা `look_skin`** আছে, একটা প্রকাশিতও
  (`যাচাইয়ের রূপ (মুছে ফেলা হবে)`, ২৫ আগস্ট)। মালিকের চলতি কোম্পানি
  ৩ — কোম্পানির রূপ ব্যক্তির বাছাই চাপা দিচ্ছে কি না, সেটাই সবচেয়ে
  সম্ভাব্য।
- ব্রাউজারে পুরনো CSS জমে আছে কি না।
- "module change hoyne" আলাদা করে বোঝা — Control Panel-এর সুইচ, না
  অন্য কিছু।
