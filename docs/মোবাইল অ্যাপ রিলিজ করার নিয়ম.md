# মোবাইল অ্যাপ রিলিজ করার নিয়ম

**তারিখ:** ১৩ সেপ্টেম্বর ২০২৬
**যার জন্য:** যিনি পরের বার ABOS Mobile-এর একটা বিল্ড কারো ফোনে পাঠাবেন।

---

## ⛔ যে একটা জিনিস হারালে ফেরানো যায় না

**`mobile/android/abos-release.jks` আর তার পাসওয়ার্ড।**

Android-এ একটা অ্যাপ যে কীস্টোর দিয়ে **প্রথম** সই হয়, চিরকাল সেটাই লাগে।
নতুন চাবি দিয়ে সই করা আপডেট কোনো ফোন নেয় না — বার্তাটাও অস্পষ্ট
("App not installed")। তখন একমাত্র পথ: **নতুন প্যাকেজ নামে নতুন অ্যাপ**, আর
প্রতিটা হ্যান্ডসেটে পুরনোটা হাতে মুছে নতুনটা বসানো।

⚠️ **git-এ কোনোটাই নেই, আর থাকবেও না** — `mobile/android/.gitignore` দুইটাকেই
ঢাকে (`**/*.jks`, `key.properties`)। অর্থাৎ **রিপো থেকে ওগুলো ফেরত পাওয়া
যাবে না।** কপি রাখার দায়িত্ব মানুষের।

⭐ **এখনই, যদি না করে থাকেন:**

1. `mobile/android/abos-release.jks` ফাইলটার কপি **অন্তত দুই জায়গায়** রাখুন,
   এই মেশিনের বাইরে (পেনড্রাইভ, ব্যক্তিগত ড্রাইভ — যেখানেই)।
2. `mobile/android/key.properties` খুলে পাসওয়ার্ডটা পাসওয়ার্ড ম্যানেজারে
   রাখুন। ⛔ ইমেইল বা চ্যাটে পাঠাবেন না।

```
চাবির পরিচয়   CN=ABOS Mobile, OU=ABOS, O=ADI, L=Dhaka, ST=Dhaka, C=BD
ধরন            RSA 4096, মেয়াদ ১০,৯৫০ দিন (≈ ৩০ বছর)
alias          abos
SHA-256        252dd4f771312fc3f2e9e73748d2b72e8c71ce8eedab6b2a3ccac034fc16131a
```

ⓘ শেষ লাইনটা মিলিয়ে দেখার জন্য — কোনো APK সত্যিই এই চাবিতে সই কিনা তা
নিচের যাচাই কমান্ডে বেরোয়।

## প্রতিবার রিলিজের ধাপ

### ১ · সংস্করণ বাড়ান — `mobile/pubspec.yaml`

```yaml
version: 0.1.0+1
#        ^^^^^ ^
#        নাম   versionCode
```

⚠️ **`+N` অংশটা প্রতিবার বাড়াতেই হবে।** Android এমন কোনো "আপডেট" নেয় না
যার versionCode আগেরটার চেয়ে বড় নয় — আর দোকানের ফোনটা সকালে ঠিক ওই পথেই
হাঁটে। নামটা (`0.1.0`) ইচ্ছেমতো, কিন্তু **সংখ্যাটা কেবল বাড়ে, কখনো কমে না**।

⚠️ নাম বদলালে `lib/core/config/app_config.dart`-এর `appVersion`-ও বদলান —
ওটা সার্ভারকে বলা হয় প্রতিটা অনুরোধে। ⓘ ভুলে গেলে `flutter test` লাল হবে
(`test/app_version_test.dart`), কারণ সংখ্যাটা দুই জায়গায় লেখা।

### ২ · যাচাই করুন, তিনটাই

```bash
cd mobile
flutter analyze                 # কোড
flutter test                    # ৭৮টা টেস্ট
flutter build apk --release --split-per-abi
```

⛔ **তিনটাই লাগে, আর তৃতীয়টা বাদ দেওয়া যায় না।** `flutter test` হোস্ট
মেশিনে চলে আর Android-এর কিছুই ছোঁয় না: ১৩ সেপ্টেম্বর ৭৭টা টেস্ট সবুজ ছিল
অথচ APK তৈরিই হয়নি, কারণ AndroidManifest-এর একটা মন্তব্যে `--` ছিল, যা
XML-এ অবৈধ। **টেস্ট বলে কোড ঠিক; বিল্ড বলে জিনিসটা আদৌ আছে।**

### ৩ · সই যাচাই করুন

```bash
"$ANDROID_SDK/build-tools/36.0.0/apksigner" verify --print-certs \
  build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
```

⭐ উত্তরে **`CN=ABOS Mobile`** থাকতে হবে। `CN=Android Debug` এলে
`android/key.properties` পাওয়া যায়নি — ঐ APK **বিতরণ করবেন না**, ওটা দিয়ে
পরে আপডেটও দেওয়া যাবে না।

ⓘ key.properties না থাকলে বিল্ড থামে না, কেবল সতর্কবার্তা দেয় — যাতে যিনি
শুধু কোড দেখছেন তাঁর কীস্টোর লাগে না। তাই এই যাচাইটা ধাপ, ভরসা নয়।

### ৪ · কোন ফাইলটা পাঠাবেন

```
app-arm64-v8a-release.apk     ১৮ MB   ← প্রায় সব আধুনিক ফোন
app-armeabi-v7a-release.apk   ১৬ MB   ← পুরনো/সস্তা ফোন (৩২-বিট)
app-x86_64-release.apk        ২০ MB   ← কেবল এমুলেটর, ফোনে নয়
```

ⓘ কোনটা লাগবে না জানলে arm64 দিয়ে শুরু করুন; "App not installed" বললে
armeabi-v7a দিন।

⚠️ Play Store-এ দিতে হলে APK নয়, **`flutter build appbundle`** (`.aab`)।

## সার্ভারের ঠিকানা

ডিফল্ট `app_config.dart`-এ বসানো (আজ `https://os.adi.com.bd/api/v1`), আর
বিল্ডের সময় বদলানো যায়:

```bash
flutter build apk --release --split-per-abi \
  --dart-define=ABOS_API_BASE_URL=https://erp.adi.com.bd/api/v1
```

⚠️ **ঠিকানা বদলালে প্রতিটা ফোনে নতুন বিল্ড লাগে** — অ্যাপের ভেতরে ওটা
বদলানোর কোনো পর্দা নেই, আর ইচ্ছে করেই নেই: একটা ভুল ঠিকানা বসিয়ে ফেলা
হ্যান্ডসেট বাইরে থেকে ঠিক করার উপায় থাকত না। তাই ডোমেইন স্থির রাখাটা
গুরুত্বপূর্ণ।

## ⛔ রিলিজ করতে পারা মানে "কাজ করে" নয়

১৩ সেপ্টেম্বর পর্যন্ত এই অ্যাপ **কেউ আসল ডেটা নিয়ে চলতে দেখেনি**। টেস্ট
প্রমাণ করে পর্দা payload ঠিক আঁকে; প্রমাণ করে না সার্ভার সত্যিই ওই payload
পাঠায় — আর ১২ সেপ্টেম্বরের ছয়টা বাগ ঠিক ওই ফাঁকটাতেই এক মাস বেঁচে ছিল।

⭐ **প্রথম APK কারো ফোনে যাওয়ার আগে একবার সত্যিকারের রাউন্ড:**

```
সাইন ইন → /me মেনু আসে → সিঙ্ক → গ্রাহকের নাম, পণ্যের দাম, বকেয়া, মজুদ
পর্দায় দেখা যায় → একটা অর্ডার লেখা → সিঙ্কের পর APPLIED আর নম্বর ফিরে আসা
```

ⓘ নাহলে প্রথম ব্যবহারকারীই প্রথম পরীক্ষক হবেন, আর তিনি একটা দোকানে দাঁড়িয়ে
থাকবেন।

## যদি কীস্টোর সত্যিই হারিয়ে যায়

সৎ উত্তর: **ঐ অ্যাপটা আর আপডেট করা যাবে না।** যা করতে হবে —

1. `applicationId` বদলান (`com.abos.abos_mobile` → অন্য কিছু), নতুন কীস্টোর,
2. প্রতিটা ফোনে পুরনো অ্যাপ মুছে নতুনটা বসান,
3. ⚠️ মুছে ফেলার আগে দেখুন **কারো ফোনে সিঙ্ক না-হওয়া অর্ডার আছে কিনা** —
   ওগুলো অ্যাপের নিজের সংরক্ষণে থাকে আর মোছার সাথে চলে যায়।

⭐ তিন নম্বরটাই এই কাগজের আসল কারণ। চাবি হারানো একটা অসুবিধা; না-পাঠানো
অর্ডার হারানো টাকা।
