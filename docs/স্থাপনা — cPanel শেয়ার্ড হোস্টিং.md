# স্থাপনা — cPanel শেয়ার্ড হোস্টিং

**তারিখ:** ১২ সেপ্টেম্বর ২০২৬
**কার জন্য:** যিনি ABOS প্রথমবার একটা cPanel হোস্টিংয়ে বসাবেন।

---

## কেন এই কাগজটা আলাদা

`infra/deploy.sh` লেখা হয়েছিল **অফিসের Mac mini**-র জন্য। ওখানে যা ধরে নেওয়া আছে, cPanel-এ তার কিছুই সত্যি নয়:

| `deploy.sh` ধরে নেয় | cPanel-এ |
|---|---|
| `/opt/homebrew/bin` PATH-এ | Homebrew নেই |
| প্রজেক্ট `/Users/mac/abos` | `/home/<user>/abos` |
| `ssh ubos-office` | `ssh <user>@<সার্ভার>` |
| nginx + Caddy, TLS Caddy-তে | LiteSpeed, TLS cPanel-এর AutoSSL-এ |
| `sudo` আছে | **নেই** — এক্সটেনশন বসানো যায় না, কেবল চালু/বন্ধ করা যায় |

তাই স্ক্রিপ্টটা ওখানে চলবে না, আর **চালানোর চেষ্টা করাও উচিত নয়** — প্রথম লাইনেই `command not found` দিয়ে থামবে, আর তার আগে ব্যাকআপের ধাপটা পেরিয়ে যাবে।

⚠️ এই কাগজটা `deploy.sh`-এর **বিকল্প নয়, অনুবাদ** — ওটা যে ছয়টা জিনিস নিশ্চিত করে, এখানেও সেই ছয়টাই করতে হবে, হাতে।

## ধাপ ০ · কেনার আগে চারটে প্রশ্ন

⛔ এই চারটের কোনো একটার উত্তর "না" হলে **ABOS ওখানে চলবে না**। কেনার আগে সাপোর্টকে লিখিতভাবে জিজ্ঞেস করুন।

1. **PHP 8.3** আছে? আর নিচের ছয়টা এক্সটেনশন চালু করা যাবে —
   `bcmath` · `mbstring` · `pdo_mysql` · `gd` · `zip` · `intl`
   ⭐ **`bcmath` আলোচনার বাইরে।** এই ব্যবস্থার প্রতিটা টাকার অঙ্ক ওটা দিয়ে গোনা হয় (কোডে ৩০ জায়গায়), আর `MoneyIsNeverAFloatTest` নামের পাহারাটাই দাঁড়িয়ে আছে এই শর্তে যে অঙ্ক কখনো float-এ যাবে না। `bcmath` ছাড়া অ্যাপ বুট হবে, তারপর প্রথম ভাউচারেই ভাঙবে।
2. **SSH shell access** দিয়ে **composer** চালানো যাবে?
   ⓘ প্যাকেজে "Shell Access — Yes" লেখা থাকলেও অনেক হোস্ট ওটা jailed রাখে আর composer বন্ধ করে দেয়। ⛔ composer ছাড়া স্থাপনা সম্ভব নয়: `vendor/` গিটে থাকে না, আর ৮,৩৬০টা ক্লাস হাতে তোলা যায় না।
3. **cron job** দিয়ে প্রতি মিনিটে একটা কমান্ড চালানো যাবে?
   ⚠️ এটা ছাড়া **রাতের ব্যাকআপ আর খাতার যাচাই কোনোদিন চলবে না** — আর সেটা নীরবে, কোনো ভুল না দেখিয়ে। `WorkSentToTheBackgroundHasSomethingToRunItTest`-এর মন্তব্যে এই ফাঁদটার কথা লেখা আছে।
4. সাবডোমেইনের **document root** `public/` ফোল্ডারে বসানো যাবে?
   ⛔ না হলে `.env`, `vendor/`, `storage/` সব ব্রাউজার থেকে পড়া যাবে — অর্থাৎ ডাটাবেজের পাসওয়ার্ড আর `APP_KEY` খোলা।

## ধাপ ১ · ডাটাবেজ

cPanel → **MySQL® Databases**

1. ডাটাবেজ বানান — নাম হবে `<user>_abos` ধরনের
2. ব্যবহারকারী বানান, **লম্বা পাসওয়ার্ড** দিয়ে
3. ব্যবহারকারীকে ডাটাবেজে যোগ করুন, **ALL PRIVILEGES**

⓵ তিনটে নাম লিখে রাখুন, `.env`-এ লাগবে।

⚠️ **MariaDB না MySQL, সেটা জেনে নিন** (cPanel-এর নিচে লেখা থাকে)। দুইটাই চলবে, কিন্তু কারণটা জানা দরকার: নম্বর সিরিজ ইঞ্জিন `SELECT … FOR UPDATE` দিয়ে সারি লক করে যাতে দুইজন একই চালান নম্বর না পান, আর অঙ্ক থাকে `DECIMAL(18,4)`-এ। MariaDB দুইটাই সমর্থন করে। ⛔ কিন্তু sqlite-এ **কোনোটাই** নেই — তাই ABOS কোনোদিন sqlite-এ চলবে না, `phpunit.xml`-এর মন্তব্যেও সেটা লেখা।

## ধাপ ৪ · নির্ভরতা

```bash
composer install --no-dev --optimize-autoloader
```

⛔ `--no-dev` বাদ দেবেন না — তাতে phpunit, larastan, faker সব নামবে, আর inode খরচ হবে অকারণে।

⚠️ **`npm` চালানোর দরকার নেই, আর সম্ভবত সুযোগও নেই** — শেয়ার্ড হোস্টিংয়ে Node থাকে না। CSS ও JS আগেই বিল্ড করা থাকে (`public/build/`), আর ওটা গিটে কমিট করা। ⓘ যদি কোনোদিন `resources/js` বা `resources/css` বদলান, **বিল্ডটা নিজের মেশিনে করে কমিট করতে হবে** — নাহলে সার্ভারে পুরনো বান্ডলই চলতে থাকবে, কোনো ভুল না দেখিয়ে।

## ধাপ ৫ · `.env`

```bash
cp .env.example .env
nano .env
```

যা অবশ্যই বদলাতে হবে:

```ini
APP_ENV=production
APP_DEBUG=false
APP_URL=https://abos.univer.com.bd

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=<user>_abos
DB_USERNAME=<user>_abos
DB_PASSWORD=<যে পাসওয়ার্ড দিলেন>

SESSION_DRIVER=database
CACHE_STORE=database
QUEUE_CONNECTION=database
```

⛔ **`APP_DEBUG=false` — এটা সবচেয়ে জরুরি লাইন।** `true` থাকলে যেকোনো ভুলের পাতায় ডাটাবেজের পাসওয়ার্ড, `APP_KEY` আর ফাইলের পথ ছাপা হয়, আর সেটা যে কেউ দেখতে পান।

⓵ `APP_ENV=production` আরেকটা কাজও করে: **`DemoSeeder` তখন চলতে অস্বীকার করে।** ঐ সিডার তিনজন ব্যবহারকারী বানায় যাদের পাসওয়ার্ড `password` আর একজনের রোল `owner` — উৎপাদনে সেটা বসা মানে ব্যবস্থার সবচেয়ে বড় চাবি সবার জানা পাসওয়ার্ডে খুলে দেওয়া। পাহারাটা ১২ সেপ্টেম্বর ২০২৬-এ বসানো হয়েছে, কিন্তু সে `APP_ENV` দেখেই সিদ্ধান্ত নেয় — তাই লাইনটা ভুল থাকলে পাহারাও ভুল দিকে তাকাবে।

তারপর:

```bash
php artisan key:generate
```

## ধাপ ৭ · ডাটাবেজ তৈরি

```bash
php artisan migrate --force
```

⛔ **`migrate:fresh` কোনোদিন নয়।** ওটা প্রতিটা টেবিল ড্রপ করে। ১২ সেপ্টেম্বর ২০২৬-এ ডেভ মেশিনে ঠিক ওটাই ঘটেছে — একটা কনফিগ ক্যাশ `DB_DATABASE` ছাপিয়ে দিয়েছিল, আর একটা টেস্ট রান পুরো ডাটাবেজ মুছে দিয়েছিল। ⚠️ **আর রানটা ১৯/১৯ পাস দিয়েছিল** — সবুজ ফলটাই ছিল ক্ষতির চিহ্ন।

⛔ **`db:seed` কোনোদিন নয়** (উপরের `DemoSeeder`-এর কারণ)।

প্রথম কোম্পানি ও মালিক বসাতে ব্রাউজারে যান:

```
https://abos.univer.com.bd/setup
```

ⓘ ওই পাতাটা কেবল তখনই খোলে যখন `users` টেবিল খালি; একজন বসলেই ৪০৪। তাই ওটা ফেলে রাখা নিরাপদ — কিন্তু **প্রথম কাজ ওটাই করুন**, কারণ যতক্ষণ খালি ততক্ষণ যে কেউ গিয়ে নিজেকে মালিক বানাতে পারেন।

## ধাপ ৮ · অনুমতি, ছক ও ক্যাশ

```bash
php artisan abos:sync-permissions
php artisan abos:sync-chart
php artisan abos:sync-deposit-kinds
php artisan abos:optimise
```

⓵ `abos:optimise` শেষে চালাতে হবে, আর **প্রতিবার কোড বা `.env` বদলানোর পরেও**। সে আগে সব ক্যাশ মুছে তারপর নতুন করে বানায় — এই ক্রমটা ১২ সেপ্টেম্বরের একটা ঘটনার ফল: একটা প্যাকেজ সরানোর পর `storage/framework/views`-এ কম্পাইল করা পুরনো ব্লেড পড়ে ছিল, আর প্রথম অনুরোধেই ৫০০ দিয়েছিল। `view:cache` একা যা নেই তা বানায়; যা আছে, বাসি হলেও থাকে।

## ধাপ ৯ · শিডিউলার (cron)

⚠️ **এই ধাপটা বাদ দিলে ব্যবস্থা দেখতে ঠিকই চলবে, কিন্তু রাতের ব্যাকআপ, খাতার যাচাই আর নির্ধারিত প্রতিবেদন — তিনটাই কোনোদিন চলবে না, আর কেউ টের পাবে না।**

cPanel → **Cron Jobs** → প্রতি মিনিটে:

| ঘর | মান |
|---|---|
| Common Settings | Once Per Minute (`* * * * *`) |
| Command | `cd /home/<user>/abos && /usr/local/bin/php artisan schedule:run >> /dev/null 2>&1` |

ⓘ PHP-র পথ হোস্ট অনুযায়ী আলাদা। `which php` দিয়ে বের করে নিন, আর **সেই পূর্ণ পথটাই লিখুন** — cron-এ `php` একা প্রায়ই কাজ করে না।

বসানোর পর যাচাই করুন:

```bash
php artisan schedule:list
```

## ধাপ ১০ · যাচাই — অনুমান নয়, মেপে

```bash
curl -sS -o /dev/null -w "%{http_code}\n" https://abos.univer.com.bd/up      # 200 চাই
curl -sS -o /dev/null -w "%{http_code}\n" https://abos.univer.com.bd/        # 302 চাই
php artisan abos:books-check                                                  # খাতা মেলে কি
```

⭐ আর **বাইরের কোনো নেটওয়ার্ক থেকে** একবার খুলে দেখুন (মোবাইল ডেটা দিয়ে, ওয়াইফাই বন্ধ করে)। ⚠️ ভেতর থেকে খোলা আর বাইরে থেকে খোলা এক জিনিস নয় — ১২ সেপ্টেম্বর ২০২৬-এ ঠিক এই পার্থক্যটাই ধরতে সারাদিন গেছে: অফিসের সার্ভার ভেতর থেকে ২০০ দিত, বাইরে থেকে টাইমআউট, কারণ ISP inbound পোর্ট আটকে রেখেছিল।

## ধাপ ১১ · DNS

সবকিছু কাজ করার পর, **তখনই** DNS বদলান:

```
abos.univer.com.bd    A    <হোস্টিংয়ের IP>
```

⓵ আগে বদলালে সাইট নামানোর সময়টা লম্বা হয়। ⭐ পুরনো IP (`27.123.254.80`) লিখে রাখুন — ফেরার দরকার হলে কাজে দেবে।

## রোলব্যাক — যদি কিছু ভাঙে

```bash
cd ~/abos
git log --oneline -5          # কোন কমিটে ছিলাম
git checkout <পুরনো-কমিট>
composer install --no-dev --optimize-autoloader
php artisan abos:optimise
```
