**তারিখ:** ২৩ নভেম্বর ২০২৬
**দুই পাশ:** সার্ভার (`fe/wa-sms`) ↔ অ্যাপ (abos-3b)
**নমুনা:** মালিকের "ok" ২৩ নভেম্বর ২০২৬ — HUXqpfhxng8823eEFrvH54 v1, ট্যাব ক (পাঠানোর পপআপ) আর গ (কাগজের পাতায় "পার্টিকে জানানো" ঘর)

## ০ · সব দরজার সাধারণ নিয়ম

- ঠিকানা `/api/v1/…`, অ্যাপের access টোকেন (`abilities:app`), জনপ্রতি থলে (`throttle:app`), কোম্পানি আর শাখা টোকেনের মানুষের।
- **কাগজ চেনা:** `type` = কাগজের মডেলের ইংরেজি নাম — ছাপার দরজার (`/documents/{type}/{id}/pdf`) একই শব্দ, যেমন `SalesInvoice`,
  `Voucher`, `PurchaseOrder`; `id` = কাগজের `public_id`। ⛔ ক্রমিক সংখ্যা চলে না।
- **পাহারা — ওয়েবের "পাঠান" বাক্সের হুবহু** (যিনি কাগজটা ছাপতে পারেন, তিনিই পাঠাতে পারেন):

| উত্তর | কখন |
|---|---|
| ৪০৪ | অচেনা `type`, কাগজ নেই, অন্য কোম্পানির, বা ছাপার দরজার চোখে নাগালের বাইরে (শাখা, গুদাম, `view` নীতি) |
| ৪০৩ `{"reason":"module_off","module":…}` | কাগজের মডিউল এই কোম্পানি/শাখার ফোনে বন্ধ |
| ৪০৩ | কাগজের ওয়েবের ছাপার চাবি নেই |
| ৪২২ | লেখা এই কাগজ আর পথের জন্য চালু নয় (`template_id`), নম্বর মোবাইল নয় (`phone`), SMS বিদেশের নম্বরে বা পথ বন্ধ (`phone`/`channel`) |
| ৪২৮ | লেখার দরজায় (`POST`) `Idempotency-Key` হেডার নেই |

- **লেখার তিন দরজা** (`whatsapp`, `sms`, `resend`) `Idempotency-Key` চায় (৮–৬৪ অক্ষর, `A-Za-z0-9_-`)। একই চাবি ২৪ ঘণ্টার মধ্যে আবার এলে
  প্রথম উত্তরটাই ফেরে, দ্বিতীয় বার্তা যায় না। ⓘ প্রতিটা চাপে নতুন চাবি; নেটওয়ার্ক ভেঙে আবার পাঠালে একই চাবি।
- লেখাটা **সবসময় সার্ভারে বানানো** — অ্যাপ লেখা পাঠায় না, `template_id` আর `locale` পাঠায়। পার্টির কাছে যা যায় আর খাতায় যা লেখা, একই।
- পড়ার দুই দরজার উত্তরে `Cache-Control: no-store`।

## ১ · পপআপ খোলা — `GET /party-messages/compose`

প্রশ্ন: `type`, `id`, `channel` = `whatsapp` | `sms`

```json
{
  "data": {
    "party": { "name": "রহমান এন্টারপ্রাইজ" },
    "phones": [ { "number": "8801711234567", "shown": "01711234567", "label": "রহমান সাহেব" } ],
    "templates": [ { "id": 12, "name": "বিক্রয় বিল", "bn": "প্রিয় …", "en": "Dear …" } ],
    "locale": "bn",
    "wame_on": true,
    "sms_on": true,
    "office_phone": "অফিসের ফোন ১"
  }
}
```

| ঘর | মানে |
|---|---|
| `phones[]` | পার্টির জানা সব মোবাইল, আন্তর্জাতিক অঙ্কে (`number`, পাঠানোর সময় এটাই) আর দেখানোর রূপে (`shown`); `label` = কার নম্বর (খালি হতে পারে)। খালি তালিকা = নম্বর নেই — অ্যাপ নিজে লেখার ঘর দেখাবে |
| `templates[]` | ঐ **পথের** আর ঐ কাগজের চালু লেখা, দুই ভাষায় আসল মান বসানো (`{party}`, `{amount}`, `{due}`, `{link}` …) — অ্যাপ যেমন আছে তেমন দেখায়, কিছু বসায় না |
| `locale` | কোম্পানির বসানো শুরুর ভাষা (`bn`/`en`) — পপআপ এটা বাছা অবস্থায় খোলে |
| `wame_on` | "WhatsApp-এ পাঠান" (wa.me) পথ চালু কি না — বন্ধ হলে বোতাম দেখাবে না |
| `sms_on` | SMS পথ চালু **আর** অফিসের ফোন বসানো — বন্ধ হলে SMS বোতাম দেখাবে না |
| `office_phone` | যে অফিসের ফোনের সিম থেকে SMS যাবে (নাম); `sms_on = false` হলে `null` |

ⓘ কাগজের জীবিত লিংক (`{link}`) দরকার হলে সার্ভার নিজেই বানায় বা আগেরটা নেয় — অ্যাপকে আলাদা করে লিংক বানাতে হয় না।

## ২ · WhatsApp — `POST /party-messages/whatsapp`

দেহ: `{ "type", "id", "template_id", "locale": "bn"|"en", "phone" }` — `phone` যেকোনো রূপে (`01711…`, `+880 1711-…`, বাংলা অঙ্কও)।

উত্তর ২০১:

```json
{ "url": "https://wa.me/8801711234567?text=…", "data": { …সারি (§৪)… } }
```

অ্যাপ `url`-টা খোলে (WhatsApp অ্যাপে)। খাতায় সারি "খোলা হয়েছে" (`status = opened`, `route = wame`) — শেষে পাঠান চাপা হয়েছে কি না কেউ জানে না,
তাই সার্ভারও তা দাবি করে না। `wame_on = false` হলে ৪০৩।

## ৩ · SMS — `POST /party-messages/sms`

দেহ: WhatsApp-এর হুবহু। লেখা SMS-এর লেখা থেকে (`compose?channel=sms`-এর `templates`)।

উত্তর ২০১: `{ "data": { …সারি… } }` — `status = waiting`, `route = phone`; অফিসের ফোন নিলে আর অপারেটর খবর দিলে অবস্থা এগোয়
(`sent` → `delivered`, বা `failed` কারণসহ)। ⛔ কেবল বাংলাদেশের মোবাইল (`8801[3-9]…`)।

## ৪ · কাগজের "পার্টিকে জানানো" ঘর — `GET /party-messages?type=&id=`

ঐ কাগজের পার্টিকে কী গেছে, নতুন আগে, সর্বশেষ ২০টা:

```json
{ "data": [
  { "id": "uuid", "channel": "whatsapp", "route": "cloud", "via": "auto", "status": "failed",
    "time": "2026-11-21T09:58:00+06:00", "created_at": "2026-11-21T09:58:00+06:00",
    "phone": "8801300000112", "reason": "এই নম্বরে WhatsApp নেই", "fell_back": true },
  { "id": "uuid", "channel": "sms", "route": "phone", "via": "auto", "status": "delivered",
    "time": "2026-11-21T09:59:00+06:00", "created_at": "…", "phone": "8801300000112", "reason": null, "fell_back": false }
] }
```

| ঘর | মান |
|---|---|
| `id` | সারির `public_id` — আবার পাঠানোর দরজায় এটাই |
| `channel` | `whatsapp` \| `sms` — চিহ্ন ও নাম |
| `route` | `wame` (বোতামে খোলা) · `cloud` (Meta Cloud API) · `phone` (অফিসের সিম) |
| `via` | `button` (কেউ চাপলেন) · `auto` (নিজে থেকে) |
| `status` | `opened` খোলা হয়েছে · `waiting` অপেক্ষায় (`route = phone` হলে "ফোনে অপেক্ষায়") · `sent` গেছে · `delivered` পৌঁছেছে · `read` পড়েছেন · `failed` ব্যর্থ |
| `time` | অবস্থার সময় — `read`→পড়ার, `delivered`→পৌঁছানোর, `sent`→যাওয়ার, বাকিতে সারির সময় (ISO-8601); পিলে `HH:MM` |
| `reason` | কেবল `failed`-এ — লাল লাইনে যেমন আছে তেমন দেখাবে; অজানা হলে `null` |
| `fell_back` | `true` = এই ব্যর্থ WhatsApp-এর পরে SMS-এ গেছে — লাল লাইনে "… → SMS-এ গেছে" (নমুনা ট্যাব গ) |

⛔ অচেনা `status`/`route` এলে অবস্থার কাঁচা শব্দ ধূসর পিলে দেখাবে, ভাঙবে না — সার্ভার ভবিষ্যতে মান যোগ করতে পারে।
ⓘ চাবি পাঠানোরই: যিনি কাগজটা পাঠাতে পারেন তিনিই এই ঘর দেখেন। ঘর খালি হলে অ্যাপ ঘরটা দেখাবে না।

## ৫ · আবার পাঠান — `POST /party-messages/{id}/resend`

দেহ নেই। একই পথে নতুন সারি; পুরনো সারি যেমন ছিল থাকে।

উত্তর ২০১: `{ "url": string|null, "data": { …নতুন সারি… } }` — wa.me-র সারিতে `url` (অ্যাপ খুলবে), বাকিতে `null`।
কাগজের লেখা নতুন করে বানানো হয় কাগজের **জীবিত** লিংকসহ (পুরনো লেখার লিংক হয়তো মরে গেছে)।

| উত্তর | কখন |
|---|---|
| ৪০৪ | সারি নেই বা শাখার নাগালের বাইরে, বা কাগজটা নাগালের বাইরে |
| ৪০৩ | কাগজের ছাপার চাবি নেই; পার্টির হিসাবের সারিতে (বাকির তাগাদা) ওয়েবের খাতার চাবি `notification.party_messages` নেই |
| ৪২২ `road` | পথটা এখন বন্ধ — কারণ লেখায় (যেমন "SMS-এর পথ বন্ধ, বা অফিসের ফোন বসানো নেই") |

## ⛔ যা অ্যাপ করবে না

- নিজে লেখা বানাবে না বা বদলাবে না; নিজে `wa.me` লিংক বানাবে না — সার্ভারের `url`।
- WhatsApp-এর লোগো দেখাবে না — নিজের চ্যাট চিহ্ন, "WhatsApp" কেবল পথের নাম হিসেবে (মালিকের নিয়ম)।
- স্ক্রিনে অঙ্ক ইংরেজিতে (মালিক, ১৬ নভেম্বর ২০২৬)।
