hp2 হল ডিপোর মেশিনের (HP, `C:\ABOS`) QA সেশন। এই branch (`hp2-qa-notes`) main-এ merge
হয় না; এটা hp2-র খাতা। সমন্বয়ক এখান থেকে পড়েন।
